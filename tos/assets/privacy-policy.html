Privacy Policy / 隐私政策

Pi Agent for TOS · Last updated / 最后更新：2026-09-23

中文

本应用不收集、不上传任何用户数据。它完全在你的 NAS 本机运行；打包者（Moechz）与其托管服务不会收到你的任何信息，应用内也没有任何遥测或统计上报。

  • 本机存储：会话记录、长期记忆与工作区数据保存在 /Volume1/@apps/piagentfortos/data。执行 apt remove 会保留这些数据，apt purge 会删除它们。
  • 网络通信：应用仅在两种情况下联网——① 你自行配置的模型服务（如 DeepSeek、OpenAI 或你的自建网关，密钥由你提供）；② 你在对话中要求智能体执行的联网操作（如下载依赖、调用 API）。为完成对话，你的提示词、会话上下文与工具输出会被发送到你选择的模型服务商，其处理方式受该服务商的隐私政策约束。
  • 不向第三方回传：本应用不会把数据发送给打包者或上游项目。
  • 日志：运行日志只写入本机 systemd 日志（journalctl -u piagentfortos），不会外传。
  • 权限：应用以专用非特权用户运行，目录访问范围由 TOS 自身的文件权限体系决定；选择工作目录时复用 TOS 官方文件管理 API。

English

This app collects and uploads no user data. It runs entirely on your NAS. Neither the packager (Moechz) nor any of their services receive information from it, and the app contains no telemetry or analytics.

  • Local storage: sessions, long-term memory and workspace data live in /Volume1/@apps/piagentfortos/data. apt remove keeps that data; apt purge deletes it.
  • Network: the app goes online only when (1) it talks to the model provider you configured (DeepSeek, OpenAI, your own gateway, …) using your own API key, or (2) you ask the agent to do something online (install dependencies, call an API, …). To run a conversation, your prompts, session context and tool output are sent to the model provider you chose, and their handling is governed by that provider's privacy policy.
  • No third-party reporting: nothing is sent back to the packager or the upstream project.
  • Logs: only local systemd logs (journalctl -u piagentfortos), never uploaded.
  • Permissions: the service runs as a dedicated unprivileged user; folder access is governed by TOS's own permission model, and the folder picker reuses the official TOS file-management API.
