# Pi Agent Desktop 定制版 0.8.8-14

**网络韧性修复版**（包含 `0.8.8-13` 的 Windows 启动修复，Windows 用户建议直接升到本版）。

## 1. 会话事件流（SSE）自愈重连

**问题**：切换网络（Wi‑Fi/有线）、休眠唤醒、或经过中转（relay）时链路抖动后，那条 SSE 长连接会断，
而客户端不自愈 —— 表现为"发消息一直没有回复"，只能刷新页面。

**修复**（`hooks/agent-session/agent-events-manager.ts`）：
- 重连不再"5 次封顶"就不再尝试（改为高上限 + 延迟封顶 30s）；
- 不再只在"认为 agent 正在运行"时才重连（有会话就重连）；
- 新增 **`visibilitychange` / `online` 唤醒重连**：页面回到前台、网络恢复时立即重连，不等退避计时器；
- 服务端 SSE 首帧下发 **`retry: 3000`**，让 `EventSource` 断线后 3 秒就重试。

## 2. 反代 / relay 场景不再 `forbidden origin`

**问题**：经中转（如 TNAS.online relay）访问时，浏览器带的 `Origin` 与反代改写后的 `Host` 不一致
→ 应用自身的同源校验直接 **403 `forbidden origin`** → 发消息、加载工具全部失败（页面却正常）。

**修复**（`lib/auth-policy.ts`）：
- 同源判定除 `Host` 外**同时信任 `X-Forwarded-Host`**（逗号链取第一段）；
- 接受浏览器自报的 **`Sec-Fetch-Site: same-origin`**（只认 `same-origin`，不认 `same-site`，避免同 site 子域发命令）；
- **403 响应体带上判定依据**（`origin` / `host` / `x-forwarded-host` / `sec-fetch-site`），便于从浏览器 Console 直接定位。

## 3. 流式响应与诊断

- 流式路由（聊天 SSE / OAuth / 文件流）补齐 **`Cache-Control: no-cache, no-transform`** 与
  **`X-Accel-Buffering: no`**，防止中间代理压缩/缓存导致事件被"憋住"；聊天心跳 30s → **15s**。
- 新增排障日志：`[origin-check]`（拒绝原因）、`[agent-api]`（命令是否到达）、`[sse]`（连接与事件计数）。

## 4. 随本版一并包含
