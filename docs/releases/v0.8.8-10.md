# Pi Agent Desktop 定制版 0.8.8-10

基于上游官方 `0.8.8` 的个人定制版第 10 次发布。维护与发布：**Moechz**。

## 本版重点：21 语界面 + 输入法回车修复 + 升级不再"看得见旧界面"

### 1. 界面支持 21 种语言（新增 19 种）
此前界面只有中文与英文；本版新增：繁體中文、日本語、한국어、Français、Deutsch、Español、
Italiano、Português、Русский、Nederlands、Polski、Türkçe、Svenska、Čeština、Magyar、
Bahasa Indonesia、Tiếng Việt、ไทย、Norsk bokmål（共 21 种）。

- 「工作台菜单 → 语言」里可选，语言名一律用该语言**自身写法**（`日本語`、`Nederlands` …）
- 「跟随系统」会按浏览器/系统语言自动选择
- （阿拉伯语 / 希伯来语暂未加入界面，因为需要 RTL 排版支持）

### 2. 修复：中文输入法下按回车会误发送消息（重点反馈项）
**现象**：用中文输入法打字，想把拼音/英文原样上屏时按回车，消息却被直接发走。
**根因**：Safari 在按回车确认候选词时**先发 `compositionend`、再发 `keydown`**，
只判断 `isComposing` 会漏判（此时它已经是 false）。
**修复**：四重判定——输入法组合状态 / `isComposing` / `keyCode 229` / 「刚结束组合 60ms 宽限期」。
同一保护也应用到**会话重命名、TOS 目录路径、新建文件夹名、技能搜索、API Key** 等输入框。

### 3. 会话右侧刻度条：两根竖线改为视觉隐形
按反馈把刻度条的「左分隔线」与「中轴标尺线」改为透明（保留结构与尺寸，刻度对齐不变）。

### 4. 修复：升级后界面还是旧的（根本原因）
此前页面文档被长期缓存（`s-maxage=31536000`），升级后浏览器仍用旧页面 + 旧 JS，
表现为「新功能装上却看不见」。现在：
- **页面/接口**：`no-cache, must-revalidate`（每次回源校验，可 304，成本极低）
- **带内容哈希的资源**：保持 `immutable` 长期缓存

今后升级会自动生效，无需再手动清缓存。

## 安装

**Windows**（本页 `Pi-Agent-Desktop-Setup-0.8.8-10.exe`）
1. 双击运行；SmartScreen 提示 →「更多信息」→「仍要运行」（未代码签名）
2. 覆盖安装，会话与配置保留

**macOS**：`Pi-Agent-Desktop-0.8.8-10-mac-universal.dmg`，拖入「应用程序」覆盖；若提示「已损坏」：
`xattr -cr "/Applications/Pi Agent Desktop.app"`

**Linux**：`Pi-Agent-Desktop-0.8.8-10-linux-amd64.deb`
