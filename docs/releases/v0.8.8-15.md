# Pi Agent Desktop 定制版 0.8.8-15

**系统提示词面板修复版**（含 `0.8.8-14` / `-13` 的全部内容，Windows 用户建议直接升到本版）。

## 1. 面板「关不掉」修复（用户反馈）

该面板此前是**全应用唯一没接统一下拉关闭机制**的浮层：没有 Esc、没有关闭按钮，
只能"再点一次同一个菜单项"才能关。

现在：**点外部 / Esc 关闭** + 面板右上角**关闭按钮**（复用 `common.close`）；
因为关闭钩子挂在共享面板容器上，**「分支」面板也一并获得同样能力**。

## 2. 面板「看起来透明、与会话内容交织」修复

**根因是层叠/包含块，不是背景色**：面板原先渲染在工具条子树内，而工具条带
`backdrop-filter: blur(22px)` —— 按规范它会成为 `fixed` 后代的**包含块**，
把面板压进工具条那 36px 的裁剪/层叠上下文里。

现在：**portal 到 `document.body`**（与工作台菜单同因同治）、底色**显式内联**（不依赖 `material-popover` 类）、
长行加 `break-words`（修横向溢出）。

## 3. 面板「看不见内容」修复

系统提示词是 pi **运行期拼装**的产物、**不落盘**（会话文件里只有对话，没有 system 消息）；
原先前端只在"每一轮跑完"或"打开时恰好正在跑"才拿得到它 → 打开空闲的历史会话必然空白 ——
那句"发送消息后将加载系统提示词"其实是**字面准确**的。

现在：
- **打开面板按需拉一次**：`GET /api/sessions/<id>?includeState` → 服务端 `peekState()`（**不重置**空闲回收计时）→ 刚跑过/正在跑的会话点开即有内容；
- 空闲会话提供**「载入系统提示词」按钮**：显式唤醒服务端 agent（读 AGENTS.md 并拼装 prompt），
  随后显示。副作用已知并接受：会话会驻留到空闲回收；**未信任的项目会 409** → 先发一条消息触发信任确认即可。
  （刻意**不**在打开面板时自动唤醒 —— "看一眼"不值得悄悄起一个 agent 实例。）

## 4. 随本版一并包含

- `0.8.8-14`：**SSE 自愈重连**（切网络 / 休眠唤醒 / 中转抖动后不再失联）+ **反代/relay 下 `forbidden origin` 修复**；
- `0.8.8-13`：Windows「启动失败（`--stack-size=16384` 超栈保留）」修复 + 打包后冒烟测试带真实 argv；
- `0.8.8-12`：Windows 原生窗口按钮（最小化/最大化/关闭）；
- `0.8.8-11 / -10`：目录移除、21 语界面、输入法回车修复、升级缓存策略。
