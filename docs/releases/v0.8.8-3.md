# Pi Agent Desktop 定制版 0.8.8-3

基于上游官方 `0.8.8` 的个人定制版第 3 次发布。维护与发布：**Moechz**。

版本号规则：`<上游版本>-<定制序号>`。本版含 0.8.8-1 / -2 的全部定制（P1–P21 源码化移植 + 审计修正 + 验收微调）。

## 本版更新（相对 0.8.8-2）

- **侧栏目录折叠状态会被记住**：手动收起的目录分组在重启应用后保持收起（此前重启或侧栏重挂载即全部展开，设定丢失）
- **切换会话自动定位到最新消息**：以前切到某个会话总是停在最早的会话历史，需要手动向下滚动；现打开即落到最新
- **DeepSeek 模型清单清理**：只保留 **DeepSeek V4.1 Flash**（旧的 V4 Flash 条目已从清单移除）

## 安装

**Windows**（本页 `Pi-Agent-Desktop-Setup-0.8.8-3.exe`）

1. 双击运行，无需管理员权限
2. 若出现 SmartScreen 蓝色提示 →「更多信息」→「仍要运行」（安装包未代码签名）
3. 安装程序会自动结束正在运行的旧进程并覆盖安装；**会话与配置保留**

**macOS**（`Pi-Agent-Desktop-0.8.8-3-mac-universal.dmg`，Intel + Apple Silicon）

打开 DMG 拖入「应用程序」覆盖；首次打开若提示「已损坏」：

```bash
xattr -cr "/Applications/Pi Agent Desktop.app"
```

## 自动更新

应用内更新源指向**本仓库** Releases（不会拉取上游官方版覆盖定制）。装有 0.8.8-2 的同事启动后会看到「新版本可用」提示，由自己决定是否下载。
