# Pi Agent Desktop 定制版 0.8.8-11

基于上游官方 `0.8.8` 的个人定制版第 11 次发布。维护与发布：**Moechz**。

> 从 `0.8.8-9` 直升本版会**一并带上 `0.8.8-10` 的全部内容**（21 语界面、中文输入法回车修复、
> 会话栏刻度条隐形、升级后不再"看得见旧界面"），详见 `docs/releases/v0.8.8-10.md`。

## 本版重点：左侧目录可以「移除」了 + 开发环境缓存修正

### 1. 新增：目录可以移除（用户反馈项，两轮迭代后定稿）

**问题**：客户端里"加进去的目录"没有办法移除，越积越多。

**首版方案被否**：在输入框「已添加目录」弹窗里每行加 hover 悬浮的 `×` —— 用户反馈「太隐蔽、设计不好」。

**定稿方案**：**左侧目录行（会话分组那一行）行尾的 `…` → 菜单里「移除」**（与侧栏会话行的
「更多操作」同一惯例，常显可见，不再 hover-only）。

- **移除范围**：侧栏分组、侧栏「历史目录列表」、输入框「已添加目录」**三处同时消失**，
  判据统一（`lib/added-dirs.ts` 的 `isDirVisible()`），不会出现"这儿删了那儿还在"
- **只从列表隐藏**：不动磁盘目录、**不删任何会话**（菜单里已写明这句提示，21 语）
- **想恢复**：重新添加即可（侧栏 📁+「新建目录」／「自定义路径…」／输入框「选择其他目录…」）
- 移除状态记得住（刷新、重启后保持）；多面板实时同步（`pi:dirs-visibility` 事件）

**聊天记录在哪、会不会丢？** 不会丢。会话存储在 `~/.pi/agent/sessions/--<把路径的 / 换成 ->--/*.jsonl`，
会话归属由文件首行记录的 `cwd` 决定；"移除"只在 `localStorage` 里写一串隐藏路径，**与记录无关**。
重新添加同一目录后，侧栏会按目录重新分组，历史消息原样回来。

### 2. 修正：开发环境（`next dev`）下 chunk 被当 `immutable` 缓存

- **现象**：改完代码刷新页面看不到新界面，误判为"没热重载"
- **根因**：`/_next/static/*` 的 `Cache-Control: immutable`（为生产环境避免回源而加）在 dev 下同样生效
  → 浏览器把 dev 的 chunk 缓存一年。本次用 Puppeteer 抓 `localStorage.setItem` 调用栈才定位到
- **修正**：`immutable` **只在 `NODE_ENV=production` 生效**，dev 改发 `no-store, must-revalidate`
  （生产行为完全不变）；`package.test.ts` 断言加了 `NODE_ENV` 门禁检查防回退

### 3. 同期一致性改动（随本版一并发布）

- 中文输入法回车误发送的修复、升级后旧界面缓存问题、会话栏刻度条隐形等 `0.8.8-10` 内容
- 21 种界面语言（新增 19 种，含繁中/日/韩/法/德/西/意/葡/俄/荷/波/土/瑞/捷/匈/印尼/越/泰/挪）

## 安装 / 升级

- **macOS**：`Pi-Agent-Desktop-0.8.8-11-mac-universal.dmg`（Apple Silicon + Intel 通用）
- **Windows**：`Pi-Agent-Desktop-Setup-0.8.8-11.exe`
- **Linux**：`pi-agent-desktop_0.8.8-11_amd64.deb`
- 已装旧版可直接用应用内「检查更新」，或下载安装包覆盖安装（macOS 覆盖后建议 `xattr -cr "/Applications/Pi Agent Desktop.app"`）

## 校验

各产物 SHA-256 由 Release 页面与 `.sha256` 文件给出；本仓库 CI（`.github/workflows/desktop-packages.yml`）
构建三平台产物。同一 commit 亦产出 TOS 应用中心包 `tos-v0.8.8.9-29`（x86_64 / aarch64）。
