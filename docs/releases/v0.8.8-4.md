# Pi Agent Desktop 定制版 0.8.8-4

基于上游官方 `0.8.8` 的个人定制版第 4 次发布。维护与发布：**Moechz**。

版本号规则：`<上游版本>-<定制序号>`。

## 本版更新（相对 0.8.8-3）

- **修 NewAPI / OneAPI 等第三方网关调用报 422**
  `422: messages[0].role: unknown variant \`developer\`` —— pi 对 reasoning 模型默认使用 OpenAI 新语义的 `developer` role，而多数第三方网关只接受 `system/user/assistant/tool`。
  本版起：对 `models.json` 中自定义的 `openai-completions` provider，若未显式声明 `compat.supportsDeveloperRole`，自动补写 `false`（pi 改用 `system` role）。
  - 你显式写 `true` 就完全尊重你的设置；官方 OpenAI / Azure 端点不做干预；幂等，无变化不写盘
  - 覆盖两条路径：模型列表 API 与 **真正发请求的 agent 会话**
- **修 Windows 主进程偶发弹窗「Titlebar overlay is not enabled」**
  根因：P22 定制移除了窗口原生遮盖条（让 macOS 红绿灯悬浮），但主题切换仍调用 `setTitleBarOverlay`——Windows 上该函数存在、窗口却未启用 overlay，调用即抛未捕获异常。现捕住并静默降级（异常只发生一次）。
- **测试基线恢复全绿**：`npm test` 612 通过 / 0 失败，`tsc --noEmit` 零错误

## 安装

**Windows**（本页 `Pi-Agent-Desktop-Setup-0.8.8-4.exe`）
1. 双击运行，无需管理员权限
2. SmartScreen 提示 →「更多信息」→「仍要运行」（未代码签名）
3. 自动结束旧进程并覆盖安装；**会话与配置保留**

**macOS**（`Pi-Agent-Desktop-0.8.8-4-mac-universal.dmg`）
拖入「应用程序」覆盖；首次打开若提示「已损坏」：`xattr -cr "/Applications/Pi Agent Desktop.app"`

更新源指向本仓库 Releases，装有 0.8.8-3 的机器启动后会提示「新版本可用」（不自动下载）。
