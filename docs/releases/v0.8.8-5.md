# Pi Agent Desktop 定制版 0.8.8-5

基于上游官方 `0.8.8` 的个人定制版第 5 次发布。维护与发布：**Moechz**。

## 本版重点：Windows 端工具能力补齐（同事反馈「很多基本技能缺失」）

### 1. Windows 现在能执行命令了（改用 PowerShell）
此前工具预设只包含 `bash`，而 Windows 上 pi 的 `bash` 工具**需要已安装 Git Bash**，否则执行时报
`No bash shell found`。结果是：不能跑 python / npm / git，不能起服务、构建、下载依赖、打开程序。
本版起 Windows 自动使用 pi 的 **`powershell`** 工具（系统自带，无需额外安装）。

### 2. 默认就带「列目录 / 按名查找 / 内容搜索」
此前默认工具集只有 `read / bash / edit / write`，**`ls`、`find`、`grep` 都不在默认集里**，
所以「列目录、找文件、搜内容」全都做不了（只能靠猜路径去读）。本版默认预置已补齐 `grep / find / ls`。

### 3. 搜索工具二进制随包内置（不再依赖联网下载）
pi 的 `grep` / `find` 依赖 `rg`（ripgrep）与 `fd`，缺失时会**运行时从 GitHub 下载**——
国内网络基本下不动，于是搜索功能等于不可用。
本版把对应平台二进制**打进安装包**（win/mac/linux 各自版本），首次启动自动装到 `~/.pi/agent/bin`，
`grep` / `find` 开箱即用、无需联网。

## 同时包含 0.8.8-4 的修复
- **NewAPI / OneAPI 等网关 422**（`unknown variant \`developer\``）：自动改用 `system` role
- **Windows 主进程弹窗「Titlebar overlay is not enabled」**：已消除

## 安装

**Windows**（本页 `Pi-Agent-Desktop-Setup-0.8.8-5.exe`）
1. 双击运行，无需管理员权限
2. SmartScreen 提示 →「更多信息」→「仍要运行」（未代码签名）
3. 覆盖安装，**会话与配置保留**

**macOS**：`Pi-Agent-Desktop-0.8.8-5-mac-universal.dmg`，拖入「应用程序」覆盖；首次打开若提示「已损坏」：
`xattr -cr "/Applications/Pi Agent Desktop.app"`

## 建议验证（Windows 同事）
1. 让 AI「列出当前目录的文件」→ 应能列出（用 `ls`）
2. 让 AI「在项目里搜索包含 xxx 的代码」→ 应能搜到（用 `grep`，无需联网）
3. 让 AI「运行 `python --version`」或「`npm -v`」→ 应能执行（用 PowerShell）
4. 让 AI「新建一个文件并写入内容」→ 应能创建
