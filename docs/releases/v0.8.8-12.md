# Pi Agent Desktop 定制版 0.8.8-12

**Windows 修复版**：本版对 macOS 无功能性改动（Mac 用户可不升级）。

## 修复：Windows 客户端缺少最小化 / 最大化 / 关闭按钮（用户反馈）

**现象**：Windows 版窗口右上角**没有任何窗口控制按钮**，只能靠 `Alt+F4` 或任务栏右键关闭。

**根因**：窗口创建用的是 `titleBarStyle: "hidden"` —— 这在 macOS 上配合悬浮的"红绿灯"效果很好。
但 **Windows 没有红绿灯**，而 P22（移除原生深色遮盖条）那次把 `titleBarOverlay`
（Window Controls Overlay，原生窗口按钮覆盖层）也一并关掉了 → 标题栏与三个按钮同时消失。

**修复**：改为按平台生成窗口选项（新增 `titleBarWindowOptions(platform, isDark)`，
见 `electron/title-bar-overlay.ts`），**只在 `win32` 重新启用 `titleBarOverlay`**：

- 原生「最小化 / 最大化(还原) / 关闭」按钮回到**内容右上角**（Windows 11 下悬停最大化按钮还有贴靠布局）
- **配色跟随主题**：暗色 `#0c1118` / 亮色 `#ffffff`（符号色 `#d9deea` / `#364152`），
  窗口创建时取系统主题打底，渲染层加载后由既有的 `set-theme` 通道实时校正
- **高度 36px**，与页面顶栏（`--toolbar-height`）等高，视觉上并入顶栏
- 页面顶栏两端早已有 `.w-titlebar { width: env(titlebar-area-width, 138px) }` 占位
  （当年 WCO 布局留下的），开启后按钮正好落在那块预留区，**不会遮挡**文件面板按钮 / 标签栏
- **macOS 与 Linux 选项不变**：macOS 继续用悬浮红绿灯，Linux 交给窗口管理器

## 影响范围

| 平台 | 本版是否需要升级 |
|---|---|
| Windows | **需要**（否则右上角没有窗口按钮） |
| macOS | 不需要（无功能性变化） |
| Linux | 不需要（无功能性变化） |

## 校验

- `electron/title-bar-overlay.test.ts` 新增 2 例：仅 `win32` 得到 `titleBarOverlay`（含 36px 高度）、
  `darwin`/`linux` 为 `undefined`；配色随主题
- `npx tsc -p electron/tsconfig.json` 与根 `npx tsc --noEmit` 均通过
- 产物由 CI（`.github/workflows/desktop-packages.yml`）构建三平台
