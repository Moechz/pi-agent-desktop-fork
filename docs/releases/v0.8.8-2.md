版本号规则：`<上游版本>-<定制序号>`。本版含此前全部定制（P1–P21 移植 + 7 项审计修正 + 验收微调）。

- **应用图标按 macOS 规范重生**：可见区 824/1024（~80%）居中、四角全透明，不再比其他应用图标大一圈（Windows/Linux 图标保持各自平台满幅惯例）

- **组内会话按修改时间降序**（活跃会话自动浮顶）
- **自动更新源改指本仓库** Releases：不会再拉取上游官方版覆盖定制（上游源已关闭）

## 安装

**Windows（本页 `Pi-Agent-Desktop-Setup-0.8.8-2.exe`）**

1. 双击运行，无需管理员权限
2. 若出现 SmartScreen 蓝色提示 → 「更多信息」→「仍要运行」（安装包未做代码签名）
3. 安装程序会自动结束正在运行的旧进程，直接覆盖安装即可

**macOS**（`Pi-Agent-Desktop-0.8.8-2-mac-universal.dmg`，Intel + Apple Silicon 通用）

1. 打开 DMG，把 App 拖入「应用程序」覆盖
2. 首次打开若提示「已损坏」或「无法验证开发者」：
   ```bash
   xattr -cr "/Applications/Pi Agent Desktop.app"
   ```
   再打开即可（未签名、未公证）
